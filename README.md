## Overview

ZEVENRA is a modern clothing storefront built for online selling in Sri Lanka. The platform supports normal orders, pre-orders, admin operations, media uploads and customer checkout.

## Main Features

- Product catalogue
- In-stock ordering
- Pre-order requests
- COD and bank transfer checkout
- Receipt upload
- Customer order tracking
- Admin management
- Product and stock control
- Cloudinary media uploads

## Tech Stack

`React` · `Vite` · `Vercel` · `Vercel Functions` · `Cloudinary`

## Local Development

```bash
npm install
npm run dev
```

## Production Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Main Flow

```text
Browse → Select Product → Cart / Pre-order → Checkout → Order → Fulfilment
```

## Notes

- Guest checkout is supported.
- Pre-orders remain separate from the normal cart until confirmed.
- Server secrets must never be committed to the repository.
